# Archesky – Business Agency Landing Page

![Archesky Business Agency Landing Page](127.0.0.1_5500_index.html%20%281%29.png)
A front-end development project created as part of my Full Stack Development training.

The objective of this project was to recreate a business agency landing page based on a design provided in Figma, translating the visual layout into HTML and CSS.

## Technologies Used

- HTML5
- CSS3
- Git and GitHub

## Project Objective

- Interpret a provided Figma design
- Reproduce the visual layout using HTML and CSS
- Apply typography, colors, spacing, and positioning
- Organize page elements to match the original design
- Practice fundamental front-end development skills

## Project Structure

- `css/` – Stylesheets
- `img/` – Images and visual assets
- `js/` – JavaScript files
- `index.html` – Main HTML file

## My Role

I implemented the provided Figma design using HTML and CSS as part of my Full Stack Development coursework.

## Project Status

Completed educational project focused on translating a Figma design into a functional web page.
